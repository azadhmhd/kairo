Export & the road to .riv

A .riv binary can only be authored in the Rive editor — but this rig removes all the hard work. Download the layered SVG, drag it into Rive (every data-part arrives as a separate layer), set the six pivots from section 09, and rebuild the state machine from sections 05 & 10. Alternatively: this rig runs as-is in Electron/Tauri today — kairo.js is dependency-free with a transparent background.
